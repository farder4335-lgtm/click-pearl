# Click Pearl

Клиентский Fabric-мод для Minecraft **26.2**: бросок эндер-жемчуга по одной кнопке (по умолчанию — боковая кнопка мыши 4), без ручного переключения слота.

## Как работает
- Жемчуг в руке — бросается сразу.
- Жемчуг в хотбаре — слот переключается, жемчуг бросается, слот возвращается обратно.
- Жемчуг во второй руке — бросается из неё.
- Если жемчуга нет — сообщение в чат.

Кнопка меняется в `Настройки → Управление → Click Pearl` (можно назначить любую клавишу или кнопку мыши, в т.ч. среднюю/боковые).

## Требования
- Minecraft 26.2, Fabric Loader ≥ 0.20.1, Fabric API, Java 25.

## Сборка
```
./gradlew build
```
Готовый jar — в `build/libs/`. Также собирается автоматически в GitHub Actions (артефакты запуска).
